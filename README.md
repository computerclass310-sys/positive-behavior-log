# سجل رصد السلوك الإيجابي

تطبيق ويب للمعلمات لرصد درجات السلوك الإيجابي للطالبات. التصميم زجاجي (بطاقات شفافة وأزرار زجاجية)، والبيانات محفوظة في قاعدة بيانات Supabase مشتركة بين كل معلمات المدرسة.

**رابط التطبيق:** https://computerclass310-sys.github.io/positive-behavior-log/

## المزايا

- **الدخول برمز تحقق:** تكتب المعلمة بريدها، فيصلها رمز من 6 أرقام. لا توجد كلمة مرور.
- **الدخول الأول فقط:** تكتب المعلمة اسمها وتختار الصفوف المسندة إليها (أول صف تختاره يصبح صفها الرئيسي)، والمادة اختيارياً.
- **الرصد:** اختيار الصف من الصفوف الاثني عشر (ثاني 1–6، ثالث 1–6) ثم الطالبة، ووصف السلوك، والدرجة (+1 / +2 / +3 / +5)، ومرفق شواهد اختياري (PDF أو صورة حتى 10 ميجابايت)، وتوقيع رقمي يُعتمد قبل الحفظ.
- **المتابعة:** تعرض صفوف المعلمة المسندة ورصدها هي فقط. فيها بطاقات الكل / المستوفيات / غير المستوفيات، وبحث، وتقرير لكل طالبة، وطباعة PDF، وتصدير Excel و Word، ومشاركة تقرير الصف مع التوجيه الطلابي.
- **الطالبات:** قائمة مشتركة بين المعلمات، مع إضافة يدوية وتعديل وحذف (لما أضافته المعلمة فقط)، واستيراد من ملف Excel أو CSV (عمود الاسم ثم عمود الصف).
- **الإعدادات:** تعديل الملف (الاسم والمادة واسم المدرسة)، والنصاب، والتوقيع الإلزامي، وتنبيه اكتمال النصاب، وصيغة التصدير، والصفوف المسندة (الضغط على صف يجعله الرئيسي، واستبدال صف، وإلغاء إسناده، وربط صف إضافي).
- **لا يُطلب رقم هوية الطالبة ولا يُخزَّن.**

## الإعداد في Supabase

قاعدة البيانات مُعدّة ومربوطة بالتطبيق. هذه الإعدادات تُضبط من لوحة Supabase:

1. **قوالب البريد:** في **Authentication → Emails → Templates** يحتوي قالبا **Confirm signup** و **Magic Link** على `{{ .Token }}` حتى يصل الرمز بدل الرابط.
2. **خادم البريد:** في **Authentication → Emails → SMTP Settings** خادم بريد خاص (مثل Gmail بكلمة مرور تطبيق)، لأن الخادم الافتراضي لا يرسل إلا لأعضاء فريق المشروع.
3. **إغلاق التسجيل:** الرابط عام، فبعد تسجيل كل المعلمات أوقفي **Allow new users to sign up** من **Authentication → Sign In / Providers**، وأضيفي أي معلمة جديدة من **Authentication → Users → Add user**.

المفتاح الموجود في `index.html` هو المفتاح العام (publishable) المصمم للمتصفح، والحماية بقواعد RLS. لا يوضع مفتاح `secret` في التطبيق أبداً.

## النشر

التطبيق منشور على GitHub Pages من الفرع `main` (المجلد الرئيسي). أي تعديل على `index.html` في `main` يظهر في الرابط بعد دقيقة أو دقيقتين.
